نظام غرس للحضور والغياب — الإصدار السريع 2.4.1

هذه النسخة تعيد طريقة العمل الأصلية السريعة:
- تسجيل الدخول يقرأ بيانات المعلمة وطلاب صفها فقط.
- لا ينشئ جلسة جديدة ولا يكتب آخر تسجيل دخول ولا ينفذ فحص Drive أثناء الدخول.
- الدخول المحفوظ على الهاتف يفتح فوراً، ثم تتحدث البيانات في الخلفية.
- بقيت الواجهة الجديدة والعمل بلا إنترنت والمزامنة التلقائية وزر «مزامنة الآن».

تحديث Apps Script مع الحفاظ على الرابط نفسه

1) افتح مشروع Apps Script الحالي المرتبط بملف Google Sheets.
2) استبدل محتوى Code.gs بالكامل بالملف الجديد واضغط «حفظ».
3) من إعدادات المشروع تأكد أن المنطقة الزمنية هي Asia/Gaza.
4) شغّل initializeClassFolderIdLinks مرة واحدة لربط مجلدات الصفوف الحالية بهوية الورقة.
5) شغّل setupDailyPdfTrigger مرة واحدة لضبط التقرير اليومي قرابة الساعة 8 مساءً.
6) افتح: نشر ← إدارة عمليات النشر.
7) اضغط القلم بجانب عملية النشر الحالية، واختر «إصدار جديد»، ثم «نشر».
8) لا تنشئ عملية نشر ثانية؛ يجب أن يبقى رابط /exec الحالي نفسه.

تحديث GitHub Pages

1) فك ضغط Ghars-studentapp-main.zip.
2) ارفع الملفات الموجودة داخل مجلد Ghars-studentapp-main إلى جذر المستودع الحالي.
3) استبدل الملفات القديمة ثم نفّذ Commit إلى الفرع main.
4) لا ترفع ملف ZIP نفسه، ولا تغيّر اسم المستودع أو إعداد GitHub Pages.
5) يبقى رابط التطبيق:
   https://romo72024.github.io/Ghars-studentapp/

التحقق بعد التحديث

- انتظر علامة النجاح الخضراء في GitHub Actions.
- أغلق صفحة التطبيق وافتحها من جديد، ثم حدّثها مرة إضافية.
- يجب أن يظهر أسفل شاشة الدخول: «الإصدار 2.4.1 — سريع».
- اختبر رابط Apps Script المنتهي بـ /exec?action=login&teacherId=CODE باستخدام كود صحيح.
- أول دخول لمعلمة لها صف وورقة موجودان هو عملية قراءة فقط.
- إذا كان Assigned Class في العمود C فارغاً، يكتب النظام أول اسم متاح:
  غرس1 ثم غرس2 ثم غرس3... وينشئ ورقة بالاسم نفسه مع جدول الحضور.
- إذا كان اسم الصف موجوداً في Teachers لكن ورقته غير موجودة، ينشئ الورقة مرة واحدة.
- عند تغيير اسم الصف، يعاد تسمية الورقة نفسها ولا تُنشأ ورقة بديلة.
- مجلد Drive يبقى مرتبطاً بـ Sheet ID، ويُعاد استخدامه عند تشغيل تقرير الثامنة.
