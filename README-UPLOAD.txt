نظام غرس للحضور والغياب — خطوات التحديث الصحيحة

مهم جداً: نفّذ قسم Apps Script أولاً. ظهور رسالة «العملية المطلوبة غير معروفة»
يعني أن GitHub يعرض الواجهة الجديدة بينما رابط Apps Script ما زال يشغّل إصداراً قديماً.

أولاً: تحديث Apps Script مع الحفاظ على الرابط نفسه

1) افتح مشروع Apps Script الحالي المرتبط بملف Google Sheets.
2) استبدل محتوى Code.gs بالكامل بالملف الجديد، ثم اضغط «حفظ».
3) شغّل الدالة setupAttendanceSystem مرة واحدة ووافق على الصلاحيات المطلوبة.
4) افتح: نشر ← إدارة عمليات النشر.
5) اضغط رمز القلم بجانب عملية النشر الحالية.
6) عند «الإصدار» اختر «إصدار جديد»، ثم اضغط «نشر».
7) لا تنشئ عملية نشر ثانية ولا تستبدل رابط /exec؛ التطبيق يحتفظ بالرابط الحالي نفسه.

ثانياً: تحديث GitHub Pages

1) فك ضغط Ghars-studentapp-main.zip.
2) افتح المستودع الحالي: romo72024/Ghars-studentapp.
3) ارفع جميع الملفات الموجودة داخل مجلد Ghars-studentapp-main إلى جذر المستودع
   واستبدل الملفات القديمة، ثم نفّذ Commit إلى الفرع main.
4) احذف أي ملفات قديمة غير موجودة في الحزمة الجديدة، ومنها tailwind.js إن بقي موجوداً.
5) لا ترفع ملف ZIP نفسه؛ GitHub Pages لا يفك الملفات المضغوطة تلقائياً.
6) لا تغيّر اسم المستودع ولا إعداد GitHub Pages. يبقى الرابط:
   https://romo72024.github.io/Ghars-studentapp/

بعد الرفع

- انتظر اكتمال GitHub Pages بعلامة صح خضراء، ثم افتح التطبيق وحدّث الصفحة مرتين.
- يجب أن ترى أسفل شاشة الدخول عبارة «الإصدار 2.2.0». إن لم تظهر فأنت ما زلت ترى ملفات قديمة.
- افتح رابط Apps Script المنتهي بـ /exec مباشرة في تبويب جديد. يجب أن يظهر رد JSON
  يحتوي على: "apiVersion":"2.2.0". إن لم يظهر، فعملية النشر الحالية لم تُحدّث بعد.
- إذا بقي الشكل القديم على هاتف سبق أن فتح التطبيق، أغلق تبويب التطبيق وافتحه مجدداً.
- أول دخول لكل معلمة يجب أن يكون بالإنترنت. عنده ينشئ Apps Script ورقة الصف تلقائياً
  مع الأعمدة: اسم الطالب، الصف، التاريخ، اليوم، الحالة، المعلمة، ويربطها بكود المعلمة.
- بعد أول دخول ناجح يمكن فتح الحساب وتسجيل الحضور بلا إنترنت.
- العمليات غير المرسلة تبقى على الجهاز، وتُرسل عند عودة الإنترنت تلقائياً، أو عبر زر
  «مزامنة الآن». لا تُحذف العملية المحلية إلا بعد أن يؤكد الخادم نجاحها.
- التوقيت المعتمد في التطبيق والتقارير هو Asia/Gaza، والتقرير اليومي مضبوط الساعة 7 مساءً.

ملاحظة أمنية

- استخدم أكواد معلمات طويلة وعشوائية وغير متوقعة، ولا تشارك ملف Teachers مع المعلمات.
- لا تضع كود المعلمة في رابط URL؛ التطبيق الجديد يرسله بطلب POST فقط.
