# نظام الحضور والغياب — غرس

هذه نسخة الواجهة الاحترافية المخصّصة للرفع إلى GitHub Pages.

## ما تغير

- تحسين تصميم الواجهة وتجاوبها مع الهواتف.
- استخدام `logo.png` شعاراً وأيقونة للتطبيق.
- إزالة تعديل اسم المعلمة واسم الصف من التطبيق كلياً؛ ويتم تعديلهما من Google Sheet فقط.
- الإبقاء على إضافة الطالب وتعديل اسمه وحذفه كما كانت.

لم يتغير رابط Apps Script أو منطق تسجيل الدخول والحضور والعمل دون إنترنت والمزامنة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة ومنطق التطبيق الأصلي |
| `styles.css` | التصميم الاحترافي الجديد |
| `sw.js` | تشغيل الواجهة دون إنترنت وتحديث ملفاتها المخزنة |
| `manifest.json` | إعدادات تثبيت التطبيق على الهاتف |
| `logo.png` | شعار غرس وأيقونة التطبيق |

## الرفع إلى GitHub

ارفع الملفات الخمسة السابقة إلى جذر المستودع مع استبدال الملفات القديمة، ثم انتظر اكتمال نشر GitHub Pages. لا تحتاج إلى تعديل أو إعادة نشر Apps Script لأن رابط الخادم لم يتغير.

إذا بقي الشكل القديم على هاتف سبق أن فتح التطبيق، أغلق الصفحة وافتحها مرة أخرى مع الاتصال بالإنترنت ليتم تفعيل نسخة التخزين الجديدة `ghars-v4.0.0`.
