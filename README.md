# نظام الحضور والغياب — غرس v5

نسخة محسّنة للعمل على الإنترنت الضعيف، مع حفظ محلي فوري ومزامنة مجمّعة مع Google Apps Script وGoogle Sheets.

## أهم التحسينات

- دخول فوري دون إنترنت لأي معلمة سبق أن دخلت مرة واحدة من الجهاز.
- حفظ الحضور والإضافات والتعديلات والحذف على الجهاز فورًا.
- إرسال عدة عمليات في طلب واحد لتقليل وقت المزامنة واستهلاك الشبكة.
- عدم إظهار نجاح المزامنة قبل وصول تأكيد حقيقي من Apps Script.
- إعادة المحاولة تلقائيًا عند عودة الإنترنت، وعند فتح التطبيق أو الرجوع إليه.
- مفتاح مزامنة مستقل لكل معلمة ولكل تاريخ، فلا يستبدل تسليم معلمة تسليم معلمة أخرى.
- تحديث اسم الصف واسم المعلمة من ورقة `Teachers` مع الإبقاء على ورقة الصف نفسها.
- ربط ورقة الصف برقم المعلمة من خلال معرّف ثابت وبيانات وصفية، وليس بالاسم فقط.
- إنشاء صف مؤقت تلقائيًا فقط عندما يكون كود المعلمة موجودًا ولا يوجد له صف.
- عدم حذف سجلات الحضور التاريخية عند حذف طالب من القائمة.
- فهرسة صفوف كل تاريخ لتحديث يوم واحد فقط بدل قراءة سجل الصف كاملًا كل مرة.

## ترتيب التركيب

1. افتح مشروع Apps Script المرتبط بجدول الحضور.
2. استبدل محتوى `Code.gs` كاملًا بالملف الجديد.
3. من **النشر > إدارة عمليات النشر** عدّل النشر الحالي واختر **إصدار جديد** ثم انشره.
4. إذا بقي رابط `/exec` نفسه فلا تعدّل شيئًا داخل `app.js`. إذا أنشأت نشرًا جديدًا برابط مختلف، ضع الرابط الجديد في المتغير `API` أعلى `app.js`.
5. ارفع ملفات GitHub السبعة إلى جذر المستودع: `index.html` و`app.js` و`styles.css` و`sw.js` و`manifest.json` و`logo.png` و`README.md`.
6. انتظر اكتمال GitHub Pages، ثم افتح التطبيق مرة واحدة بالإنترنت وأعد تحميل الصفحة.

## تركيب أول مرة للمعلمات

- تفتح كل معلمة التطبيق بالإنترنت مرة واحدة وتدخل كودها.
- بعد ظهور الاسم والصف والطلاب، يمكنها استخدام التطبيق دون إنترنت.
- عند التسليم تظهر أولًا عبارة أن البيانات محفوظة على الجهاز.
- لا يظهر **تم التسليم والمزامنة بنجاح** إلا بعد تأكيد وصولها إلى الشيت.

## بنية أوراق البيانات

- ورقة `Teachers`: العمود A كود المعلمة، العمود B اسم المعلمة، العمود C اسم الصف.
- ورقة `Students`: العمود A اسم الصف، العمود B اسم الطالب.
- أوراق الصفوف لا تُنشأ مجددًا عند تغيير الاسم؛ يتغير اسم الورقة الحالية وتُحدّث بياناتها.

## ملاحظة مهمة

لا تغيّر أسماء الورقتين `Teachers` و`Students`. ويمكن تعديل اسم المعلمة أو الصف من ورقة `Teachers`؛ يطبّق النظام التعديل على الورقة المرتبطة عند أول دخول أو مزامنة لاحقة.
