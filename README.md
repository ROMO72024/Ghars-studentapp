# نظام الحضور والغياب — مدرسة وروضة غرس الحديثة (الإصدار 3.0)

واجهة تعمل **بدون إنترنت بالكامل** على هاتف المعلمة، وتزامن نفسها تلقائياً مع Google Sheet
فور توفّر الاتصال. كل تعديل يقابله **Update في مكانه** داخل الشيت — لا صفوف مكرّرة.

---

## لماذا تغيّرت المعمارية؟

النسخة السابقة كانت تُقدَّم من داخل Apps Script نفسه. هذا يعني أن الصفحة **لا تُفتح أصلاً بدون إنترنت**،
لأن نطاق `googleusercontent.com` لا يسمح بتسجيل Service Worker. لذلك:

```
┌──────────────────────────┐        ┌───────────────────────────┐
│  GitHub Pages            │  JSON  │  Apps Script (/exec)      │
│  الواجهة (PWA)           │ ─────► │  API فقط                  │
│  تُخزَّن على الجهاز        │ ◄───── │  يكتب في Google Sheet     │
│  وتعمل بلا إنترنت        │        │  ويولّد PDF الساعة 8 مساءً │
└──────────────────────────┘        └───────────────────────────┘
```

---

## الملفات

| الملف | مكانه |
|---|---|
| `apps-script/Code.gs` | داخل مشروع Apps Script المرتبط بالشيت |
| `web/index.html` | مستودع GitHub (الواجهة كاملة في ملف واحد) |
| `web/sw.js` | مستودع GitHub (التخزين للعمل بلا إنترنت) |
| `web/manifest.json` | مستودع GitHub |
| `web/icon-192.png`, `web/icon-512.png` | مستودع GitHub (يمكن استبدالها بشعار المدرسة) |

## خطوات التركيب

### 1) الخادم — Apps Script

1. افتح الشيت ← **Extensions ▸ Apps Script**.
2. احذف كل محتوى `Code.gs` القديم والصق محتوى `apps-script/Code.gs` الجديد.
3. **احذف ملفات `Index.html` و `CSS.html` و `JS.html` القديمة** — لم تعد مستخدمة.
4. راجع `CONFIG` في أعلى الملف:
   - `MASTER_FOLDER_ID` و `LETTERHEAD_FILE_ID` موجودان كما هما.
   - `SPREADSHEET_ID` اتركه فارغاً ما دام السكربت مرتبطاً بالشيت.
5. **Deploy ▸ New deployment ▸ Web app** بالإعدادات التالية:
   - Execute as: **Me**
   - Who has access: **Anyone**
6. انسخ رابط `/exec` — ستحتاجه في الخطوة التالية.

> عند أي تعديل لاحق على `Code.gs` استخدم **Deploy ▸ Manage deployments ▸ ✏️ ▸ Version: New**
> حتى يبقى الرابط نفسه ولا تحتاج لتعديل الواجهة.

### 2) الواجهة — GitHub Pages

1. ارفع محتويات مجلد `web/` إلى مستودعك (في الجذر أو داخل `docs/`).
2. افتح `index.html` وابحث عن السطر رقم واحد في قسم الإعداد:

   ```js
   var API = "https://script.google.com/macros/s/PASTE_YOUR_DEPLOYMENT_ID/exec";
   ```

   الصق مكانه رابط `/exec` الذي نسخته.
3. **Settings ▸ Pages ▸ Deploy from a branch** واختر الفرع والمجلد.
4. افتح الرابط الناتج (`https://<اسمك>.github.io/<المستودع>/`) — يجب أن تظهر شاشة الدخول.

### 3) تجهيز البيانات (مرة واحدة)

من محرّر Apps Script، شغّل هاتين الدالتين بالترتيب من قائمة الدوال:

| الدالة | ماذا تفعل |
|---|---|
| `repairData` | توحّد أسماء الصفوف بين `Teachers` و `Students` وأسماء الأوراق، وتوحّد صيغة عمود التاريخ |
| `ensureAllClassSheets` | تُنشئ ورقة لكل صف مذكور في `Teachers` وليس له ورقة |
| `setupDailyPdfTrigger` | تُفعّل توليد PDF يومياً الساعة 8:00 مساءً بتوقيت غزة |

### 4) التثبيت على هاتف المعلمة

افتحي الرابط في **Chrome** ← قائمة المتصفح ← **إضافة إلى الشاشة الرئيسية**.
بعد أول فتح تعمل الأيقونة **بدون إنترنت نهائياً**.

## ما أُصلح في بياناتك الحالية

فحصتُ ملف الإكسل ووجدت ثلاث مشكلات كانت ستُعطّل النظام:

1. **٢٠ طالباً مخفيّون.** صفّهم مكتوب في `Students` بالأرقام العربية‑الهندية
   `تمهيدي (٤)  ركن رُسُل` بينما الورقة اسمها `تمهيدي (4)  ركن رُسُل`.
   لن تراهم المعلمة أبداً بالمطابقة الحرفية.
2. **مسافات زائدة.** `Teachers` يحتوي `" أول  (4) ركن نبوغ"` بمسافة بادئة، والورقة بدونها.
3. **عمود التاريخ مختلط.** بعض الصفوف تخزّن التاريخ كنوع `Date` وبعضها كنص `"2026-09-02"`،
   فتفشل مقارنة «هل سُجّل هذا اليوم؟» ويُضاف صف مكرّر.

الحل في الكود: دالة `normKey_` توحّد قبل المقارنة (أرقام عربية/فارسية ← لاتينية، إزالة التشكيل
والتطويل، توحيد أ‑إ‑آ ← ا و ى ← ي و ة ← ه، طيّ المسافات المكررة). ودالة `isoOf_` تقرأ التاريخ
بأي صيغة وتعيده `yyyy-MM-dd`. أما `repairData` فتصلح الشيت نفسه مرة واحدة.

**ملاحظة:** `رابع 4 منابر المسائي` و `رابع 4 منابر المسائيي` يبقيان صفّين منفصلين — الفرق حرف
حقيقي وليس اختلاف تنسيق. إن كانا صفاً واحداً فادمجهما يدوياً.

## كيف يعمل بلا إنترنت

| الحالة | السلوك |
|---|---|
| فتح التطبيق بلا إنترنت | يفتح فوراً من ذاكرة الجهاز بكامل القائمة وحالة اليوم |
| تحديد حاضر/غائب/مأذون | يُحفظ في `localStorage` لحظياً — لا يُرسل شيء |
| الضغط على **تسليم الحضور** | تُبنى دفعة واحدة وتدخل طابور المزامنة |
| إضافة/تعديل/حذف طالب، تعديل اسم المعلمة أو الصف | تدخل الطابور فوراً وتُرسل مباشرة إن وُجد إنترنت |
| لا يوجد إنترنت | يبقى الطابور محفوظاً، والعدّاد يظهر فوق زر المزامنة 🔄 |
| عودة الإنترنت | مزامنة تلقائية خلال ثوانٍ |
| فشل الإرسال | إعادة محاولة تصاعدية 5 ← 10 ← 20 ← 40 ← 60 ثانية، ثم كل 45 ثانية |
| زر 🔄 | مزامنة يدوية فورية، أو تحديث القائمة من الشيت إن كان الطابور فارغاً |

انقطاع الكهرباء أو إغلاق التطبيق لا يفقد شيئاً: الحالة والطابور محفوظان على القرص، ويُستأنفان
عند الفتح التالي.

## قواعد الحفظ في الشيت

| العملية في التطبيق | ما يحدث في الشيت |
|---|---|
| تسليم الحضور | **Upsert** بالمفتاح (اسم الطالب + التاريخ): الصف الموجود يُحدَّث، وغير الموجود يُضاف |
| تعديل اسم طالب | Update في `Students` **و** في كل سجلات الحضور السابقة لذلك الاسم |
| حذف طالب | حذف صفه من `Students` فقط — سجلات الحضور تبقى للأرشيف |
| تعديل اسم المعلمة | Update في `Teachers` **و** في عمود «المعلمة» بورقة الصف |
| تعديل اسم الصف | إعادة تسمية الورقة + Update في `Teachers` و `Students` وعمود «الصف» + مزامنة مجلدات Drive |
| دخول معلمة بلا صف | يُولَّد اسم `ركن <اسمها>` فريد، يُكتب في `Teachers`، وتُنشأ ورقة جديدة بالعناوين الصحيحة |

كل عملية تحمل `opId` فريداً، والخادم يتذكّره ٦ ساعات — فإعادة الإرسال بعد انقطاع لا تُنفَّذ مرتين.
وكل عمليات الكتابة تعمل داخل `LockService` فلا تتضارب معلّمتان.

## ملاحظات تشغيلية

- **الافتراضي أن كل الطلاب حاضرون.** المعلمة تغيّر الاستثناءات فقط، ثم تُسلّم.
- **يوم جديد** = إعادة ضبط تلقائية إلى «حاضر» للجميع عند أول فتح بعد منتصف الليل.
- **الدخول برقم المعلمة فقط**، والرقم يقبل الحروف (`F1981`) والأرقام (`4646`).
  أول دخول فقط يحتاج إنترنت.
- **عند تعديل `index.html` لاحقاً**: غيّر `VERSION` في `sw.js` (مثلاً `ghars-v3.0.1`)
  وإلا ستبقى الهواتف على النسخة القديمة المخزّنة.
- **الحد الأقصى** ٤٠٠ سجل في الدفعة الواحدة، و١٢٠ حرفاً لأي حقل.

## استكشاف الأخطاء

| العرض | السبب الغالب |
|---|---|
| «تعذّر الوصول إلى الخادم» عند الدخول | النشر ليس على **Anyone**، أو رابط `API` غير صحيح |
| القائمة فارغة رغم وجود طلاب | اسم الصف في `Students` لا يطابق — شغّل `repairData` |
| التعديلات لا تصل الشيت | افتح 🔄 وراقب الشريط الملوّن؛ اللون البرتقالي = بانتظار الإنترنت |
| لا يُنتج PDF | تحقق من `MASTER_FOLDER_ID` ومن أن `setupDailyPdfTrigger` شُغّلت مرة |
| التطبيق لا يتحدّث بعد رفع نسخة جديدة | لم تُغيّر `VERSION` في `sw.js` |
